Survive the Zombeans 

Description:
Survive the Zombeans is a post-apocalyptic, infinite wave-based zombie survival built using basic Unity shapes and amateur voice acting. Designed with my students, 
this game focuses on fun and survival strategy, letting players battle endless waves of zombies in a simple but challenging environment.

How to Play:

Move your character with  WASD.
Jump with the spacebar.
Reload with R.
Shoot the Zombeans with the left click.
Survive as long as you can, waves get harder over time!
Watch your health and keep moving.

Features:

Wave-based zombie survival
Infinite gameplay
Helpful tutorial

Built With:

Unity

Notes:
This game was built to teach my students game development, guiding them through the entire process from concept to finished game. 
It’s simple, intentionally rough, but full of chaotic zombean survival fun.
